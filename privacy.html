FlipComp Privacy Policy

Effective October 24, 2026

FlipComp reads the Facebook Marketplace listing you are looking at and sends the listing text, and sometimes its main photo, to the FlipComp server. The server uses an AI model from Anthropic or OpenAI to turn the listing into an eBay search. FlipComp then loads eBay's sold listings for that search from your own browser and shows the results next to the listing. FlipComp does not read your Facebook or eBay account details, does not show ads, and does not sell or share your data.

What FlipComp reads on Facebook

FlipComp only reads Facebook Marketplace listing pages (addresses that contain /marketplace/item/). On those pages it reads the listing's title, price, category, condition, description and the address of its main photo. It also reads whether the listing is a vehicle or a rental, so that it can skip those.

FlipComp does not read the seller's name or profile, your messages, your Facebook account or any other Facebook page. The extension is loaded on facebook.com because Facebook changes pages without reloading them, but outside listing pages it only checks the page address.

What is sent to the FlipComp server

When you check a listing, FlipComp sends the following to its server, which runs on Cloudflare:

  • The listing's title, price, category, condition, description (up to 1,500 characters) and Facebook listing number.
  • The listing's main photo, reduced to 512 pixels, but only when the text is not enough to tell what the item is.
  • A random ID that FlipComp creates when it is installed. It is used to count free lookups and is not linked to your name or accounts.
  • If you have opened the FlipComp payment page, your ExtensionPay key, so the server can confirm with ExtensionPay whether you have Pro.
  • If you type your own eBay search, that search.
  • Whether this copy of FlipComp was installed new on version 1.2.0 or later, and when, and, if you open the Pro plans or click one, that you did and which plan (yearly or monthly). This is for the Pro price test described below; the install time is used to check whether the install came after the test started, and is not stored.

Like any website, the server also receives your IP address. FlipComp turns it into a code made with a secret key (a keyed hash), which can't be turned back into the address without that key. The code is used only to limit how many free lookups can come from one internet connection (so reinstalling FlipComp doesn't give more), and it is deleted within 91 days of the first free lookup from that connection. Cloudflare, which runs the server, also counts requests per IP address for a minute at a time to stop floods of requests.

How the AI is used

The server sends the listing text, and the photo when needed, to one of two AI services: Anthropic's Claude API, or the OpenAI API. One of them answers each lookup, and the other is used only if the first one fails. The AI answers with an eBay search, a short name for the item, its likely condition and a shipping size. Each request also carries the one-way code of your install ID (described above), so the AI provider can tell users apart if someone misuses the service. It never carries your name, email or IP address.

For free users, a listing photo is first checked by OpenAI's moderation service, and a photo it flags is never sent on.

Neither Anthropic nor OpenAI uses data sent through their APIs to train their models. Both may keep API data for up to 30 days to watch for abuse, and FlipComp asks OpenAI not to store its answers. Anthropic's privacy center and OpenAI's API data policy describe how each handles API data.

What the FlipComp server stores

Below, a "one-way code" is a hash: it can be matched against the same ID again, but it can't be turned back into the ID. Pro users are counted by a one-way code of their ExtensionPay key instead of their install ID.

  • The AI's answer for each listing (the suggested eBay search, the item name, condition and size) for 14 days, so the next person who checks the same listing gets the answer without another AI request. It is filed under a one-way code made from the listing's details, not under the listing number.
  • The lookups each install made that day: the one-way code of the install ID and the Facebook listing number of each listing checked, so the same listing isn't counted twice in a day. These are deleted after 2 to 3 days.
  • For free users, a count of free lookups for the install: one row per listing checked, holding the one-way code of the install ID and a one-way code made from the install ID and the listing number together (not the listing number itself), with the date. It is how the 10 free lookups are counted and how reopening a listing stays free. These rows are deleted after a year.
  • A cost record for each AI request: the one-way code of the install ID, the date, whether it was a free or Pro lookup, the AI model, whether a photo was sent, the number of AI tokens used, the cost and whether it worked. It does not include the listing number. These are kept for 180 days so the developer can see what the service costs and trace misuse.
  • Whether a one-way code of an ExtensionPay key belongs to a Pro subscriber, for up to 60 days.
  • For installs in the Pro price test: which of the two Pro prices the install is shown, and the dates it ran out of free lookups, opened the Pro plans and clicked a plan (with whether it was yearly or monthly). From ExtensionPay: whether it paid, which plan it bought and its price, and whether it later cancelled or stopped paying. These are kept under the one-way code of the install ID, never with an email address or card details, and are deleted a year after the install joined the test.
  • Daily totals (lookups and AI spending), which contain no IDs.

Cloudflare also keeps the server's own logs for a few days, for fixing errors. They record events such as "AI answered" or "used the title instead", with token counts and cost, but not listing numbers, listing text or photos.

The server does not store listing descriptions or photos.

What FlipComp does on eBay

To find sold prices, FlipComp loads eBay's sold-listings search for the item directly from your browser. Since July 2026, eBay only shows sold listings to signed-in members, so these requests use your own eBay sign-in, the same as if you opened the search yourself. If eBay refuses a background request, FlipComp opens the same search in a background tab and closes the tab once it has read the results.

From those pages FlipComp reads the sold listings' titles, prices, shipping costs, sale dates and item numbers. It does not read your eBay account details, messages, purchases or watchlist, and nothing from eBay is sent to the FlipComp server. FlipComp limits how often it loads eBay pages, and it never tries to get past eBay's security checks.

What FlipComp stores on your computer

FlipComp stores the following in your browser's extension storage on your own computer:

  • Your settings, such as eBay fee rates, shipping costs and deal score thresholds.
  • The random install ID described above.
  • Recent results, so that reopening a listing is free: listing results for 24 hours and eBay search results for 6 hours.
  • For Pro users, a history of your last 500 lookups and your saved eBay searches. You can clear the history or download it as a file on the Settings page.
  • A record of when eBay pages were loaded, used only to limit how often FlipComp asks eBay.
  • Your plan and the number of lookups left today, as the FlipComp server last reported them.
  • The Pro prices the FlipComp server last said to show, and whether this copy was installed new on version 1.2.0 or later.
  • If you have opened the payment page, your ExtensionPay key and the account details ExtensionPay returns for it (such as your email address and subscription status). ExtensionPay's code saves these in the browser's sync storage, so if you use your browser's sync they are copied to your other computers signed in to the same browser profile.

Payments and Pro

Pro subscriptions are handled by ExtensionPay, and payments are processed by Stripe. When you subscribe, you enter your email address and payment details on ExtensionPay's and Stripe's own pages, not inside the extension. FlipComp never sees your card details.

The developer can see the email address and subscription status of paying users in the ExtensionPay dashboard, and uses them only to provide Pro and to answer support requests. ExtensionPay's and Stripe's own privacy policies describe how they handle your information.

Pro price test

From version 1.2.0, FlipComp is comparing two Pro prices with new installs, for about eight weeks. Which price an install sees is chosen from its random install ID. FlipComp shows that price before you pay, and checkout charges that price. Installs from before version 1.2.0 keep the price they had. The server records listed above for the test are used only to compare the two prices and choose one.

Problem reports

If you click "Report a problem", your email program opens a new message that includes the address of the listing, the title and price FlipComp read, the kind of problem and your browser version. Nothing is sent unless you choose to send that email.

What FlipComp does not do

  • It does not sell, rent or share your data.
  • It does not show ads or track you across websites.
  • It does not read any website other than Facebook Marketplace listings, eBay search pages and extensionpay.com.
  • It does not use your data for anything other than pricing Marketplace listings, providing Pro and choosing Pro's price. This use of data follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Permissions

  • storage: saves your settings and the results described above on your computer.
  • offscreen: reads eBay's result pages in a hidden page inside the extension.
  • facebook.com: reads Marketplace listings and shows the FlipComp card on them.
  • www.ebay.com: loads eBay's sold-listings searches and reads the background tabs FlipComp opens.
  • signin.ebay.com: notices when eBay asks you to sign in, so FlipComp can tell you.
  • fbcdn.net (Facebook's image server): loads a listing's main photo when the AI needs it.
  • extensionpay.com: lets the payment page tell the extension that a payment went through.

Children

FlipComp is not directed at children under 13, and it does not knowingly collect information from them.
